# Mini E-Commerce — Infra

Docker Compose orchestration tying together the backend, client portal, admin portal, and MongoDB for the Mini E-Commerce assessment project.

## Related repos
- [mini-ecommerce-backend](https://github.com/II-Fedaa-II/mini-ecommerce-backend)
- [mini-ecommerce-client-portal](https://github.com/II-Fedaa-II/mini-ecommerce-client-portal)
- [mini-ecommerce-admin-portal](https://github.com/II-Fedaa-II/mini-ecommerce-admin-portal)

## Local dev convention
Clone all four repos as sibling folders under the same parent directory, then run `docker compose up --build` from this repo.

Full setup instructions and the "why 4 repos" rationale will be added as the project is built out.
